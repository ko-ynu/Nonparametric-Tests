# Nonparametric-Tests
You can perform nonparametric tests. You can test for differences, test proportions and independence, analyze correlations, and check the shape and normality of distributions.

# Nonparametric Test Bench (ノンパラメトリック検定ツール)

ブラウザ上でデータ入力から検定の実行、論文用の記述例作成、Rコードの生成までが完結する、ノンパラメトリック検定に特化したWebアプリケーションです。

専用の統計ソフトをインストールすることなく、ブラウザ（HTMLファイル）を開くだけで即座にデータ分析が可能です。**すべての計算はクライアントサイド（ブラウザ内）で実行されるため、機密性の高いデータが外部サーバーに送信されることは一切ありません。**

## ✨ 主な特徴

* **🔒 100% ローカル動作**: データのアップロードやサーバーでの演算を行いません。プライバシーとセキュリティが完全に保護されます。
* **📊 豊富な検定手法**: 差の検定、比率・独立性の検定、相関、正規性・分布の検定など、主要な14種類のノンパラメトリック手法を網羅しています。
* **📝 APA準拠の記述例を自動生成**: 検定を実行すると、そのまま和文論文のドラフトとして使える結果の記述例（APAスタイル風）を自動出力します。
* **💻 Rコード自動生成機能**: 分析に使用したデータと、実行した検定のRスクリプトを結合して出力。コピーしてJASPのRコンソールやRStudioに貼り付けるだけで、即座に同じ分析を再現できます。
* **可視化と事後検定**: Plotly.jsによる直感的なグラフ描画（箱ひげ図、散布図、ヒストグラムなど）に対応。3群以上の検定では事後検定（Bonferroni補正付き）も自動で実施します。

## 🧮 対応している検定手法

**【差の検定】**
* マン・ホイットニーの $U$ 検定
* ウィルコクソンの符号順位検定
* 符号検定
* クラスカル・ウォリス検定（+ Dunnの事後検定）
* フリードマン検定（+ Wilcoxon事後検定）

**【比率・独立性の検定】**
* カイ二乗検定（独立性）
* フィッシャーの正確検定
* マクネマー検定
* コクランの $Q$ 検定

**【相関関係】**
* スピアマンの順位相関係数 ($\rho$)
* ケンドールのタウ ($\tau$)

**【分布の形状・正規性の確認】**
* コルモゴロフ・スミルノフ検定（1標本・2標本）
* シャピロ・ウィルク検定
* アンダーソン・ダーリング検定
* ラン検定（ランダム性）

## 🚀 使い方

環境構築やインストールは一切不要です。

1. **アプリを開く**: リポジトリ内の `index.html`（または `index_3.html` 等）をChrome, Edge, Safariなどのモダンブラウザで開きます。
2. **データの入力**: CSVファイルをテキストエリアにドラッグ＆ドロップするか、エクセル等からデータをコピーして貼り付けます（1行目は変数名のヘッダーにしてください）。
3. **検定の選択と変数の指定**: 実施したい検定手法をクリックして選び、分析に使用する列（変数）をセレクトボックスから指定します。
4. **解析を実行**: 「検定を実行する」ボタンを押すと、即座に統計量、グラフ、論文記述例、Rコードが出力されます。

## 🛠 技術スタック

* **HTML / CSS / JavaScript (Vanilla)**: ビルドツール不要のシングルファイル構成。
* **[Plotly.js](https://plotly.com/javascript/)** (CDN経由): インタラクティブなグラフ描画に使用。
* その他の統計計算（正規分布・カイ二乗分布・各種検定ロジックなど）は、外部ライブラリに依存せずJavaScriptでスクラッチ実装されています。

## ⚠️ 免責事項・注意事項

* 本ツールの統計計算ロジックは標準的なアルゴリズムに基づいて実装されていますが、ブラウザの浮動小数点演算の仕様等により、RやSPSSなどの商用統計ソフトと微小な誤差（小数点以下の末尾など）が生じる場合があります。
* 高度な厳密性が求められる学術論文や業務においては、本ツールで生成された「Rコード」を使用して、R環境（JASP等）で最終確認を行うことを推奨します。
